Språkförändring

Hur mycket bolaget skrivit om sitt riskavsnitt sedan i fjol, mätt som cosinuslikhet. Intel ligger på 0,69 — medianbolaget på 0,99.

Tonläge

Andelen negativa ord, med Loughran–McDonalds finanslexikon. Oracle gick från 0,7 % till 4,8 % på ett år.

Röda flaggor

Formuleringar som betyder något exakt: going concern, material weakness, kontrollbalansräkning. Med negationsfilter, annars tänds de för alla.

Nya riskstycken

Vilka stycken som inte fanns i fjolårets rapport. Bolagets egna, juridiskt granskade ord om vad som förändrats.

Svenska rapporter hämtas som PDF via MFN, amerikanska som 10-K direkt från SEC. Allt körs lokalt. Ingen inloggning, inga API-nycklar, ingen data som lämnar datorn.

Det ovanliga

Den försöker motbevisa sig själv

Varje 30 juni bakåt i tiden ställs frågan: hur hade modellen rangordnat bolagen med enbart den information som var publicerad då? SEC:s XBRL-data innehåller inlämningsdatum för varje siffra, så det går att göra på riktigt. Sedan mäts avkastningen tolv månader framåt.

  • 01Point-in-time. Ett bokslut för 2019 som lämnades in i februari 2020 finns inte i universumet i juni 2019.
  • 02Ojusterade kurser för börsvärdet. Använder man justerade blir gamla P/E-tal fel med exakt splitfaktorn.
  • 03Nollkontroll. Samma protokoll med slumpmässiga poäng, 300 omgångar. Ryms resultatet i turen får det inte kallas något annat.
  • 04Kraven sätts i förväg, inte efter att resultatet setts.
Resultat

Nio prov. Noll godkända.

Det jag höll på att missa

Ett p-värde på 0,003 — som var en bugg

Insynsköp var den sista kandidaten med publicerat forskningsstöd. Första körningen gav +5,8 procentenheter med p = 0,003. Ett tydligt, statistiskt säkerställt "insynsköp fungerar".

Det var fel. När ett anrop till Finansinspektionen misslyckades cachades det tomma svaret — i fem år.

102 av 125 tidsfönster låg kvar som permanent tomma. Fyra hela år saknades. På det trasiga underlaget såg signalen ut att fungera. Med komplett register — 106 403 transaktioner — blev svaret −0,4 procentenheter, p = 0,75.

Ett signifikant p-värde är inte bevis på att signalen finns. Lika ofta är det bevis på att datan är trasig.
